AI Studio is Aura's creative workspace.

| Create | What you can do |
| --- | --- |
| **Images** | Generate and edit images from a description or a reference photo. |
| **Video** | Turn prompts or images into short videos. |
| **Music** | Compose songs, then edit sections — insert, restyle, save edits and apply them together. |
| **Speech** | Turn text into natural narration. |

You can also ask for images right in chat.

<Info>AI Studio requires Pro or Elite. Free members can generate 2 images per rolling hour in chat.</Info>
