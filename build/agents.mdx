Agents do work for you on a schedule or when something happens — no need to ask each time.

## Examples

- Every morning, summarize industry news and email it to me.
- When a new lead arrives, research the company and add notes to my CRM.
- Every Friday, build a sales report in Google Sheets.

## How they work

<Steps>
  <Step title="Describe the job">Write what the agent should do in plain language.</Step>
  <Step title="Choose a trigger">A schedule, or an event in a connected app.</Step>
  <Step title="Review and approve">Risky actions — sending, deleting, spending — ask for your approval first.</Step>
  <Step title="Watch it run">Every run shows its steps, files and results.</Step>
</Steps>

Agents run in a secure cloud workspace and can use your connected apps, the web and a built-in code sandbox.

<Info>Agents are available on Pro and Elite.</Info>
