Work Mode can turn information from files, public sources and connected apps into a finished result. A good request makes the result and its boundaries explicit.

## Give Aura the whole job

<Steps>
  <Step title="Name the source">Identify the app account, document, folder, URL or attached file. Include a date range when it matters.</Step>
  <Step title="Define the transformation">Say what to summarize, compare, calculate, extract or change. Include the fields and exclusions you care about.</Step>
  <Step title="Specify the output">Ask for a Word document, PDF, Excel spreadsheet, CSV, native app document or a reply in chat. Name the destination folder and intended audience.</Step>
  <Step title="Set action boundaries">Say “read only,” “draft only — do not send,” or exactly which live changes you want. Tools can change real accounts.</Step>
</Steps>

> Read the attached sales spreadsheet. Calculate monthly revenue and the five largest customers, create an Excel report with a summary sheet, and save it in the Finance folder in my Google Drive. Do not email or share it.

## Documents, spreadsheets and code execution

| Result | What to request |
| --- | --- |
| Editable written document | Word / .docx with the sections and formatting you need |
| Fixed-layout document | PDF with the intended audience and page layout |
| Workbook | Excel / .xlsx, including sheet names, calculations and charts |
| Portable data | CSV with explicit column names and filters |
| Cloud document | Name the connected provider and native format, such as Google Docs |
| Analysis in chat | A table, summary, calculations and source links |

For larger analysis, calculations, bulk transformations or complex file creation, Aura can use a code-execution workbench. This is a task working environment, not an additional connection to your accounts. Ask for the real output file and check its contents rather than treating code or a filename as a completed deliverable.

## Attach once or reuse across a project

Use [chat attachments](/chat/files) for a task-specific source. Use a [Project knowledge base](/chat/projects) for material that should guide several conversations. Knowledge Base preserves original file formats; producing a different output format does not replace your original upload.

## Follow progress and check completion

Read the tool steps in the conversation. A task may need several app actions before the requested result exists. Open the returned attachment or app link and check:

- The content is present, not an empty document or an unexecuted draft.
- The calculations, date range and source match your request.
- The correct account and destination folder were used.
- Any send, share or edit actually happened only where you asked for it.

A partial result is not the same as a finished multi-step task. If a connection or provider fails, check the account for completed actions before requesting another send or edit. Stopping a conversation does not undo a change already accepted by an external app.

## Follow-up, history and recurring work

Continue in the same conversation when refining a result: name the file or app record you want changed. Work Mode conversations appear in **Work Mode chats**; reopen the appropriate thread instead of mixing unrelated tasks. Start a fresh conversation or separate Project for a different goal.

For hands-free requests, use [voice with Iris](/chat/voice). For a schedule or event-driven job, use [Aura Agents](/build/agents) on Pro or Elite; the chat request alone is not a recurring schedule.
