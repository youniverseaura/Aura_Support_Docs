Skills are expert playbooks. Click **Skills** in the builder chat, or type **/** and pick one. Text after the name sets the focus — for example `/seo-review the pricing page`.

| Skill | What it does |
| --- | --- |
| `/code-review` | Finds bugs, risky code and clean-up opportunities. |
| `/database-optimization` | Checks tables, queries and data rules for speed and safety. |
| `/seo-review` | Reviews titles, descriptions, structure and speed for search. |
| `/accessibility` | Checks keyboard, screen-reader, contrast and tap-target problems. |
| `/video-creator` | Builds an animated video that plays inside your app. |

## Review first, fix second

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/review.jpg" alt="Glass clipboard with severity dots and a magnifier" />
</Frame>

The four reviews report problems by severity with a step-by-step plan — and change nothing until you choose which fixes to apply. They start from your latest [scan](/builder/scans) findings so work isn't repeated.

<Note>A skill is a normal build run and uses build credits.</Note>
