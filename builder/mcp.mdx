MCP (Model Context Protocol) servers let the build agent read up-to-date vendor documentation and use live tools while it builds — so it doesn't guess at an API.

## Already connected

Every project arrives with servers for Google developer documentation, Google Cloud Run, Google Maps Places, Cloudflare documentation, Exa (live web search) and Context7 (current docs for libraries and frameworks).

## Add your own

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/connect.jpg" alt="Two glass puzzle pieces clicking together" />
</Frame>

Open **Setup & keys → MCP** and add a remote server. When the agent recommends a service, it checks public MCP registries for an official server from that vendor.

## Common questions

<AccordionGroup>
  <Accordion title="Which servers come with every project?">
    Google developer docs, Google Cloud Run, Google Maps Places, Cloudflare docs, Exa and Context7.
  </Accordion>
  <Accordion title="How do I add my own?">
    Open Setup & keys → MCP and add a remote server.
  </Accordion>
  <Accordion title="What is MCP, and how is it different from an API key?">
    MCP is a protocol that lets the build agent use a server's documentation and tools. An API key is a credential a service may require. Adding an MCP server helps the agent during development; it does not replace keys your running app needs. See [Setup & keys](/builder/setup-keys).
  </Accordion>
</AccordionGroup>
