## History

Every build leaves a version. Each entry shows what changed; **View changes** opens the details. Restoring costs credits but is usually cheaper than asking the agent to undo its own work.

## Data

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/data.jpg" alt="Glass database beside a data table with a filter funnel" />
</Frame>

**Settings → Data** is a spreadsheet-style view of your app's real tables. Search, filter, edit, add and delete records — free, because it doesn't run the agent.

## Logs

**Settings → Logs** shows live errors from the running app. Copy the exact error into chat for the fastest fix.
