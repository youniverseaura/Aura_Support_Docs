## History

Every build leaves a version. Each entry shows what changed; **View changes** opens the details. Restoring costs credits but is usually cheaper than asking the agent to undo its own work.

## Data

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/data.jpg" alt="Glass database beside a data table with a filter funnel" />
</Frame>

**Settings → Data** is a spreadsheet-style view of your app's real tables. Search, filter, edit, add and delete records — free, because it doesn't run the agent.

## Logs

**Settings → Logs** shows live errors from the running app. Copy the exact error into chat for the fastest fix.

## Common questions

<AccordionGroup>
  <Accordion title="Is editing data free?">
    Yes. The Data view doesn't run the agent, so it costs nothing.
  </Accordion>
  <Accordion title="Should I restore or ask the agent to undo?">
    Restoring from History is usually cheaper.
  </Accordion>
  <Accordion title="Where do I find errors?">
    Settings → Logs. Copy the exact error into chat for the fastest fix.
  </Accordion>
  <Accordion title="What is the difference between app versions and database backups?">
    App versions cover code changes. Database backups cover records such as sign-ups and orders. Both appear in **App versions**, but they are not interchangeable: reverting a screen is different from replacing saved data. Select **Live** or **Preview** carefully before a database action.
  </Accordion>
  <Accordion title="Can I restore data to a specific time?">
    Use the point-in-time controls in **App versions → Database backups** within the available 30-day window. Restoring replaces data saved after the chosen point and requires the owner to type the app ID. A backup is taken first, but review the selected environment and time before confirming.
  </Accordion>
</AccordionGroup>
