## Roles

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/roles.jpg" alt="Three glass badges with eye, gear and pencil icons" />
</Frame>

| Role | Can |
| --- | --- |
| **Viewer** | See the project and preview. |
| **Editor** | Chat with the builder and make changes. |
| **Admin** | Manage settings and people. |

## Who pays

The owner pays for the work. Give each collaborator their own credit cap so nobody spends more than you expect. Each chat only sees its own project.

## Common questions

<AccordionGroup>
  <Accordion title="Who pays when a collaborator builds?">
    The project owner. Set a credit cap for each collaborator.
  </Accordion>
  <Accordion title="What's the difference between editor and admin?">
    Editors chat with the builder and make changes. Admins also manage settings and people.
  </Accordion>
  <Accordion title="Can an admin manage mobile releases?">
    Yes. Admins can build and ship mobile apps; the project owner pays for the build. Removing a signing key or disconnecting a store account remains owner-only. See [Mobile permissions](/builder/mobile-apps#who-can-do-what).
  </Accordion>
</AccordionGroup>
