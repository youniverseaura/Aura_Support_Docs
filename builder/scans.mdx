The **Security** tab lists findings by severity — Critical, High, Medium, Low, Info — with a risk score and an open-issue count.

## How it checks

- **Three independent AI reviewers** — GPT-6 Luna, Gemini 3.8 Flash and Claude Haiku — audit and cross-examine the same code.
- **A rule engine that learns** — curated rules, rules it writes itself, rules on trial, and its own precision tracking.
- **Live threat intel** — new attack patterns are pulled in as they appear.

Each finding is labelled **Rule**, **AI** or **Rule + AI**. Unused starter code is deliberately not flagged, so you only see real risks.

## Safe dependency upgrades

When a library needs updating, Aura checks compatibility, picks the lowest safe stable version, runs a real production build to verify it, and rolls back automatically if anything fails.

## What it costs

| | Cost |
| --- | --- |
| Automatic security scans | Free |
| Scans you start by hand | Credits |
| Applying a fix | A build run (one critical security fix a day is free) |

Fixes pause while your app is publishing. When Security and [Performance](/builder/performance) both have open items, **Fix all together** sends them as one cheaper build.
