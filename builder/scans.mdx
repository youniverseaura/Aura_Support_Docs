## Security

The **Security** tab lists findings by severity — Critical, High, Medium, Low, Info — with a risk score. Three independent AI reviewers check the same code alongside a rule engine that learns over time.

## Performance

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/performance.jpg" alt="Glass speedometer in the fast zone" />
</Frame>

The **Performance** tab finds slow pages, bloat, stale code and things that might break.

## What it costs

| | Cost |
| --- | --- |
