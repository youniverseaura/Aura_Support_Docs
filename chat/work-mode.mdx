Work Mode turns Aura from an assistant that _answers_ into one that _does_. It brings connected apps, multi-step execution and reusable project knowledge into one working conversation.

## Start your first task

<Steps>
  <Step title="Open Work Mode">
    Choose **Work Mode** from Aura's workspace navigation. In Quick Chat, you can also enable **Work Mode** from the composer's **\+** menu.
  </Step>
  <Step title="Describe the complete result">
    Say what to read, what to create or change, which account to use, and where the result should go.
  </Step>
  <Step title="Connect the required apps">
    Use the connection card when an account is needed. Public sources may work without a login.
  </Step>
  <Step title="Follow the work and inspect the result">
    Read the tool progress, open the returned file or app link, and check that the destination and content match your request.
  </Step>
</Steps>

<Tip>
  Try: “Read the meeting notes I attached, create a task list with owners and due dates, and save it as an Excel file.” Start with a read-only or file-creation task before asking for changes to live accounts.
</Tip>

## Work Mode versus the three response modes

**Unlimited, Orchestration and Frontier** describe how Aura answers. **Work Mode** describes what Aura can do with tools and connected accounts; it is not a fourth response mode. Project Chat keeps the Tool Router enabled and adds project context. Quick Chat can enable Work Mode without creating a project.

Under the hood, Work Mode runs on the [**Tool Router**](/chat/tool-router) — the bridge between you and your apps. It reads your request, picks the right app and action, and runs each step in order.

## What it can do

- Read and reply to email in Gmail or Outlook
- Create and edit Google Docs, Sheets and Slides
- Find, organize and share files in Google Drive
- Post to Slack, create calendar events, update CRMs and task boards
- Chain steps together: *"Summarize this week's unread emails into a Doc and share it with my team."*

## Connecting an app

<Steps>
  <Step title="Ask for the task">Describe what you want done in plain words.</Step>
  <Step title="Connect when asked">If the app isn't connected yet, Aura shows a connect button. Sign in with your own account.</Step>
  <Step title="Aura finishes the job">You'll see each step it takes and a link to the result.</Step>
</Steps>

Aura connects to more than **1,500 apps**. Many — like web search, weather and public data — need no sign-in. For websites without an app connection, use the [Browser Tool](/chat/browser-tool).

<Info>Work Mode is available on Essential and above. Essential members can use Work Mode but cannot create Projects.</Info>
