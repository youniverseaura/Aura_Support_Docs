Pick a mode from the picker above the composer.

| Mode | Best for | How it works |
| --- | --- | --- |
| **Balanced** | Everyday questions | One fast, capable model with live web search. |
| **Thinking** | Harder problems | Spends more time reasoning before answering. |
| **Orchestration** | Important decisions | GPT, Claude, Gemini and Grok answer independently, then Aura compares them and writes one combined answer. |
| **Frontier** | The toughest work | The most powerful models at higher reasoning levels. |
| **Unlimited** | High-volume chatting | A fast model for plans that include unlimited chat. |

## When to think longer

<Frame>
  <img
    src="https://cdn.youniverse.ai/blog-hero/docs/thinking.jpg"
    alt="Glass brain with glowing thought paths and an hourglass"
  />
</Frame>

Use **Thinking** or **Frontier** for math, planning, code and multi-step reasoning. Use **Orchestration** when being wrong is costly — Aura shows where the models agree and where they don't. Learn more in [How orchestration works](/learn/how-orchestration-works).

## Quick Chat and Project Chat

- **Quick Chat** is your everyday chat from the home screen.
- **Project Chat** happens inside a [Project](/chat/projects) and always has your project files and connected apps available.

<Note>Thinking, Orchestration and Frontier use more credits than Balanced. See [Plans & credits](/account/plans).</Note>
