The **Tool Router** is the bridge between you and your apps. It's the engine that powers [Work Mode](/chat/work-mode): you describe what you want in plain words, and the Tool Router figures out which app and which action gets it done.

## How it works

<Steps>
  <Step title="You ask in plain words">
    _"Summarize this week's unread emails into a Doc and share it with my team."_
  </Step>
  <Step title="The Tool Router picks the tools">
    It reads your request, looks at your connected apps, and chooses the right actions — here: read Gmail, create a Google Doc, share it.
  </Step>
  <Step title="Aura acts, step by step">
    Each action runs in order. You see every step as it happens, with a link to the result.
  </Step>
</Steps>

## What it can reach

- More than **1,500 apps** — Gmail, Outlook, Google Docs, Sheets, Slides, Drive, Slack, calendars, CRMs, task boards and more
- **No-sign-in tools** like web search, weather and public data work instantly
- The [Browser Tool](/chat/browser-tool) covers websites that have no app connection

## Where it's used

| Surface | Tool Router |
| ------- | ----------- |
| Quick Chat | Optional — turn it on from the **+** menu |
| Project Chat | Always on, scoped to the project's knowledge |
| Work Mode | Always on — it _is_ Work Mode's engine |

<Info>
  The Tool Router only uses apps **you** have connected, and it asks before sensitive actions. Connect an app once and it stays available in every chat.
</Info>
