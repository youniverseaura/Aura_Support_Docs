A **Project** is a workspace for one topic, client or goal. Every chat inside it can use the project's files.

## Knowledge base

Upload documents, spreadsheets, PDFs and images to a project's knowledge base. Aura keeps the original format — a `.docx` stays a `.docx` — and finds the right passage when you ask.

## Google Drive sync

Link a Drive folder to a project and Aura keeps it in sync, so new files are available automatically.

## Chat files vs. knowledge base

- **Chat files** are attached to a single message.
- **Knowledge base** files belong to the whole project.

<Info>Creating Projects requires Pro or Elite.</Info>
