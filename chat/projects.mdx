A **Project** is a workspace for one topic, client or goal. Every chat inside it can use the project's files.

## Knowledge base

Upload documents, spreadsheets, PDFs and images. Aura keeps the original format — a `.docx` stays a `.docx` — and finds the right passage when you ask.

## Google Drive sync

<Frame>
  <img
    src="https://cdn.youniverse.ai/blog-hero/docs/drive-sync.jpg"
    alt="Glass folder and cloud linked by sync arrows"
  />
</Frame>

Link a Drive folder to a project and Aura keeps it in sync, so new files are available automatically.

## Chat files vs. knowledge base

|  | Chat files | Knowledge base |
| --- | --- | --- |
| Scope | One message | The whole project |
| Best for | Quick questions | Reference material you'll reuse |
