A **Project** is a workspace for one topic, client or goal. Project Chat keeps the Tool Router on and uses that project's knowledge and instructions to guide the work. Start a separate project for a different client or purpose rather than mixing unrelated reference material.

## Work Mode with lasting context

<Steps>
  <Step title="Choose a project">
    Open Work Mode and select the project you want to work in.
  </Step>
  <Step title="Add reusable references">
    Put shared documents and instructions in its knowledge base. Attach a file to an individual message when it is only needed for that task.
  </Step>
  <Step title="Give a scoped task">
    Name the project reference, connected account, output format and destination. For example: “Using our proposal template, prepare a Word proposal from these notes and save it in the client's Drive folder.”
  </Step>
</Steps>

Project knowledge helps Aura find relevant material; it does not make every document equally relevant to every turn. When a particular file matters, identify it explicitly.

## Knowledge base

Upload documents, spreadsheets, PDFs and images. Aura keeps the original format — a `.docx` stays a `.docx` — and finds the right passage when you ask.

Link a Drive folder to a project and Aura keeps it in sync, so new files are available automatically.

## Chat files vs. knowledge base

|  | Chat files | Knowledge base |
| --- | --- | --- |
| Scope | One message | The whole project |
| Best for | Quick questions | Reference material you'll reuse |

<Info>Creating Projects requires Pro or Elite.</Info>

## Common questions

<AccordionGroup>
  <Accordion title="Which plans can create Projects?">
    Pro and Elite.
  </Accordion>
  <Accordion title="Does Aura change my file formats?">
    No. A .docx stays a .docx.
  </Accordion>
  <Accordion title="Can a project follow a Drive folder?">
    Yes. Link a folder and new files sync automatically.
  </Accordion>
  <Accordion title="Why should I name the reference file in my project request?">
    Project knowledge provides relevant context, but not every document is relevant to every turn. Identify the file or template that matters and specify the output and destination. Use a separate project for a different client or purpose.
  </Accordion>
</AccordionGroup>
