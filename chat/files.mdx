Tap the paperclip or drag files into the composer. Aura reads PDFs, Word documents, spreadsheets, slides and images.

## Ideas to try

- *"Summarize this contract and flag anything unusual."*
- *"What's in this photo, and what's the brand?"*
- *"Compare these two proposals in a table."*

## Analyze data

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/spreadsheet.jpg" alt="Spreadsheet grid rising into 3D charts" />
</Frame>

Upload a spreadsheet and ask for totals, trends or charts. Name the output format you need — for example Excel, CSV or PDF — and ask for the completed file. Your original source is not replaced by the generated result. See [Tasks, files and results](/work-mode/tasks-and-results) for larger analysis and multi-step Work Mode jobs.

<Note>Files attached to a message belong to that chat. To reuse files across chats, add them to a [Project's knowledge base](/chat/projects).</Note>

## Common questions

<AccordionGroup>
  <Accordion title="Which files can Aura read?">
    PDFs, Word documents, spreadsheets, slides and images.
  </Accordion>
  <Accordion title="Can I reuse files across chats?">
    Yes, add them to a Project's knowledge base.
  </Accordion>
  <Accordion title="Can I get an editable Excel or Word file instead of a summary?">
    Yes. Name the format, the information to include and whether you want a download or a file in a connected folder. For a workbook, specify sheets and calculations. See [Tasks, files and results](/work-mode/tasks-and-results).
  </Accordion>
</AccordionGroup>
