Some tasks require interacting with a website rather than reading it. For those, turn on **Browser Tool** in the composer's **+** menu. Aura opens a real browser, navigates pages, clicks and fills in forms for you.

<Info>
  Browser Tool requires **Pro or Elite** and Work Mode / Tool Router to be on. Essential includes connected-app Work Mode, but not Browser Tool. The browser is opt-in for each chat; Aura does not silently enable it.
</Info>

## Connected apps and Browser Tool can work together

You can ask Aura to collect information through a connected app and complete a website task in the same conversation. Work Mode handles the app actions; the browser handles the interactive website steps. Reading a public URL alone does not require the browser.

## Browser Vault

The gear beside Browser Tool opens its credential vault. Saved logins are encrypted and matched to the relevant website when a browser task needs them. Keep credentials in the vault rather than pasting passwords into your request. A saved login does not enable Browser Tool or authorize an unrelated website.

## How it works

<Steps>
  <Step title="Switch it on">Browser Tool is off by default and only runs in chats where you turn it on.</Step>
  <Step title="Describe the task">*"Check the opening hours on this site and book a table for Friday at 7."*</Step>
  <Step title="Watch it work">Aura shows what it's doing. It can work alongside your connected apps in the same chat.</Step>
</Steps>
