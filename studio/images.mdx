Open **AI Studio → Imagine → Image** to create artwork from a written description or existing pictures.

## From idea to image
<Steps>
<Step title="Describe the result">Include the subject, composition, lighting, style and intended use. For a product picture, specify what must remain unchanged.</Step>
<Step title="Choose a model and format">Choose an available image model, aspect ratio, resolution and generation count. Options depend on the model; use the displayed credit estimate before generating.</Step>
<Step title="Add references">Use reference images to communicate identity, objects or visual direction. Only upload material you have permission to use.</Step>
<Step title="Generate and review">Inspect the result before using it. Open previous work from Explore or History, then reuse it for another generation.</Step>
</Steps>

## References and focused edits
References guide the output, but they are not a promise of exact reproduction. Describe both what should change and what should stay.

For a focused edit, use the available masking controls to mark the area to change. Keep the request local: “Replace the background with a bright studio, preserving the product.” Model support determines which editing controls are available.

## Reuse and iterate
Use **Remix** from previous work to revisit its settings and make a new variation. Change one important detail at a time so you can compare results clearly. Use a finished image as a reference for a [video](/studio/video) or [lip-sync clip](/studio/lip-sync).

<AccordionGroup>
<Accordion title="Can I control exact spelling or small details?">Specify the text and placement clearly, then inspect the output. Image generation can still distort letters or fine details.</Accordion>
<Accordion title="Why do available settings change?">Different models accept different resolutions, references and editing options. A disabled control is not an option that will be silently applied.</Accordion>
<Accordion title="Is image generation covered by chat ZDR?">No blanket guarantee applies. Imagine displays its own Non-ZDR notice; avoid sensitive prompts and references.</Accordion>
</AccordionGroup>
