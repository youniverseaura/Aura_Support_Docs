Open **AI Studio → Speech** to turn written text into narration. **Settings** configures the next generation; **History** opens previous speech.

## Choose a voice
The voice picker has **Explore** and **My Voices**, with language, accent, category and gender filters. Preview voices before committing to a long script. Voice choice and delivery settings work together; the same words can sound very different across voices.

## Choose a model
| Model | Intended use |
| --- | --- |
| Flash v2.5 | Fast speech generation. |
| Multilingual v2 | Natural multilingual narration and longer-form speech. |
| v3 (expressive) | Emotional delivery and supported inline audio tags. |

Model limits vary. Use the character count and selected model's limit shown in the workspace rather than treating every model as interchangeable.

## Delivery controls
| Control | What it changes |
| --- | --- |
| Speed | How quickly the voice speaks. |
| Stability | Delivery consistency versus variation. |
| Similarity | Adherence to the selected voice's character. |
| Style Exaggeration | Strength of the voice's stylistic delivery where supported. |
| Speaker boost | Voice similarity enhancement where supported. |
| Language | The language used for synthesis. |
| Output format | Available PCM, MP3 or Opus export settings. |

Some controls depend on the model. Do not expect a disabled setting to affect the result.

## Expressive scripts
With a compatible expressive model, tags such as `[laughs]`, `[whispers]` and `[sighs]` can guide delivery. Place them close to the phrase they should affect. Punctuation and short paragraphs also help make a script easier to speak naturally.
