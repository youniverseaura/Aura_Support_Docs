Open the **Triggers** tab to choose what starts your Agent. Turn on as many as you like.

| Trigger | What it does |
| --- | --- |
| **When you press run** | Always available. Starts a run from Run now. |
| **On a schedule** | Runs by itself at the times you pick — every few minutes, daily, weekdays, monthly. Read in your own time zone. |
| **From a chat** | You or Aura can hand it a job mid-conversation. |
| **When a connected app does something** | New email, new order, new row — the app tells the Agent instantly. |
| **From a web address** | Gives the Agent a private link. Anything that can send a request (a form, Zapier, your own app) can start it. |
| **Quiet check-ins between runs** | Takes a short look on its own and only speaks up or acts if something's worth it. Check-ins slow down when nothing happens and speed back up when something does. |

## Booked one-time runs

Ask "remind me at 3:15 PM to check the shipment" or "run this tomorrow at 9" and the Agent books an exact-time run. You'll see it under **Booked one-time runs** in Triggers.

## Incoming webhooks

The **Incoming webhooks** panel shows what can send events to the Agent and everything it has received, so you can confirm deliveries.

## What happens if it's busy?

An Agent never runs twice at once. If a scheduled time arrives while it's still working, that tick is queued and runs once it finishes — nothing is skipped silently and nothing overlaps.
