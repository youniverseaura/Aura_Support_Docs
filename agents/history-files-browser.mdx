You can always see exactly what an Agent did.

## History

Every run is listed with its trigger, status, duration and cost. Open a run to see each step: the tool it used, what it found and what it changed.

## Files

Reports, spreadsheets, documents and images an Agent creates are kept in the **Files** tab. Files are stored encrypted. Agents can also read every file in your project knowledge bases.

## Browser

When the job needs a website without an app connection, the Agent uses a real cloud browser.

- **Watch live** while it works, and take over to sign in if needed.
- **Latest browser sessions** keeps recordings so you can replay what it did (the most recent five).
- One browser per account: sign in once and every Agent stays signed in.

## Code sandbox

Agents have a private code workspace for data crunching, file conversion and calculations. Scripts that worked are saved for the next run.

<AccordionGroup>
  <Accordion title="How long are recordings kept?">
    The latest five browser sessions per Agent are kept.
  </Accordion>
  <Accordion title="How can I check what an Agent changed?">
    Open its run in **History** for the trigger, status, cost and individual tool steps. Use **Files** for generated outputs and **Browser** for available session replays. Inspect the destination service as well when the job changes a live account.
  </Accordion>
