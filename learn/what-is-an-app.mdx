Every app the AI Builder makes has three layers:

| Layer | What it is | Example |
| --- | --- | --- |
| **Screens** | What people see and tap | Menu page, cart, sign-in form |
| **Logic** | The rules behind the screens | Calculate a total, send a receipt |
| **Data** | Where information is kept | Products, orders, users |

<Frame>
  <img src="https://cdn.youniverse.ai/blog-hero/docs/data.jpg" alt="Glass database beside a data table" />
</Frame>

You don't need to build these yourself — describe what you want and the builder handles all three. Knowing them helps you ask for changes clearly.
