The best first project is one you'll use yourself every day. A habit tracker is exactly that.

![A glass habit tracker phone](/images/use-cases/habits.jpg)

## What to ask for

> Build a habit tracker. I can add habits like "read 20 minutes" or "gym", check them off each day, see my current streak for each, and a weekly view showing which days I completed. Calm, minimal design.

The Builder creates the tracker, the streak logic and the weekly view. It works on your phone's browser, so it's always with you.

## Take it further

- **Reminders** — pair it with an Aura Agent that nags you at 8pm if today's habits are open.
- **Notes** — add a short journal field per day.
- **Stats page** — completion percentage per habit per month.
- **Share** — a read-only link so a friend can see your streaks.

![From a prompt to a finished app](/images/use-cases/prompt-to-app.jpg)

## Tips

- Personal apps are the cheapest way to learn the Builder — no users to disappoint.
- Add it to your phone's home screen and it feels like a native app.
