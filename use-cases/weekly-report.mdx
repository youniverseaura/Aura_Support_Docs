**You'll use:** an [Agent](/build/agents), Google Sheets and your CRM.

<Steps>
  <Step title="Try it once in chat">*"Pull this week's closed deals from my CRM, total them by rep and put the result in a new Google Sheet with a chart."*</Step>
  <Step title="Check the result">Adjust columns or the chart until it's right.</Step>
  <Step title="Schedule it">Create an Agent with the same instructions, set to run every Friday at 4 PM.</Step>
</Steps>
