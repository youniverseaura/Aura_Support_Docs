| | Quick Chat | Project Chat |
| --- | --- | --- |
| Best for | One-off questions | Ongoing work on one topic, client or goal |
| Files | Attached to a single message | Shared knowledge base for every chat |
| Connected apps | Optional, via Work Mode | Always available |

## When to start a project

Start a [Project](/chat/projects) when you'll come back to the same subject — a client account, a book, a product launch. Every chat inside it can use the project's files.
